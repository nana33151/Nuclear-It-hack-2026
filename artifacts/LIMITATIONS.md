# Ограничения решения

## Поддерживаемые условия

- Освещение: дневное + искусственное, без прямого контрового света.
- Плотность: до 6 человек в кадре одновременно.
- Скорость: пешеходная (≤ 1.5 м/с).
- Окклюзии: короткие (< 3 с).
- Камеры: статичные, 5 калиброванных гомографий.
- Запись: синхронная, 25 FPS.
- Сцена: помещение с зеркалом (mirror filter включён).

## Известные ограничения

### 1. Fish-eye / дисторсия

**Что:** крайние боксы проецируются с ошибкой 0.3–0.8 м. `bbox_bottom_center`
— грубая аппроксимация «ног».

**Что делаем:** уточняем отображение с помощью "паспортных" данных камеры.

### 2. Кривая гомография / ручная калибровка

**Что:** при неточных точках BEV-гейт (`bev_max_speed=3.0`, `bev_min_travel=0.25`)
режет валидные handover'ы при малом gap.

**Что делаем:** `bev_min_travel` заменить на распределение скоростей

### 3. ReID на мелких кропах

**Что:** в коридоре один человек часто < 40 px → `usable_for_reid=False` →
mean-RGB (32-dim). Solider (768) и color (32) несравнимы.

**Что делаем:** гейт `same_cam_reid_dim_mismatch` блокирует сравнение;
`split_by_reid` режет трек при смене размерности.

**Ограничение:** если весь трек — color-fallback, склейка только по цвету+времени.

### 4. Mirror filter использует геометрию помещения
**Что:** YOLO считывает отражение в зеркале как человека

**Что делаем:** для отсечения отражений используется проекция и сравнение координат с положением зеркала

**Ограничение:** Эта реализация опирается на ручную настройку

### 5. Окклюзии,пересечения и вход/выход

- Окклюзии > `track_buffer` (~3 с) → новый ID.
- Вход/выход за FOV — нет предсказания следующей камеры.
- Пересечения нескольких похожий людей(особенно если один из них не успел распознаться YOLO) почти гарантированно ведут к смешению ID

## Что можно доделать

- Авто-калибровка гомографий - не строить гомографии вручную, а калибровать их по траекториям людей
- Детекция позы / ключевых точек.
- Распознавание лиц.
- Мультипомещение / мультиэтаж.
- Трекинг не-`person` (животные, транспорт, п редметы).
- Ray-casting для отсечения отражений с использованием геометрии - строим линию пересечения с полом и проводим из левого нижнего угла луч к ногам человека - у реального человека сначала будут ноги, а затем линия пересечения стены и пола
